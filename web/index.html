NEWVIEW / CONNECTED DEVICES

NewViewDevice

Bring your personalized dashboard to your phone, computer, and TV browser with a private encrypted pairing link.

01 · PAIR

Connect a trusted device

Create a private link here, open it on your other device using the same NewView website, and join the same layout.

Pairing controls require a secure HTTPS connection and browser encryption support.

02 · DASHBOARD SYNC

What travels with you

Widget selection, widget order, and your active workspace. Private CSV files, passwords, screen video, and installed apps remain on your device.

Changes are checked about every 15 seconds while the dashboard is visible. Cloudflare KV storage is eventually consistent.

03 · FLOATING VIDEO

Screen streaming

Experimental WebRTC viewer for authorized, explicitly shared browser screens on the same local network. Use the connection tools below, then open Markets while the viewer stays visible. Full Android phone capture and cloud signaling are not implemented.

Permission-based browser demo · local network
SECURITY

Private pairing, not account login

Anyone with the complete pairing link can read or change the shared layout. Only use it with your devices. Disconnecting this device does not revoke links already shared.

Cloud sync needs the NEWVIEW_SYNC storage binding on the deployed Worker; a local APK opened as a file cannot use it.
